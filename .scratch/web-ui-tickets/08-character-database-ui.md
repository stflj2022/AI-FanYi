# 08: 人物数据库 UI

**What to build:**
实现人物数据库的查看和编辑功能。用户可以查看项目中的人物列表，查看人物详情（包括原声演员、音色状态），编辑人物信息，以及查看人物的音色档案。

**Blocked by:** 01-web-ui-foundation, 02-user-authentication, 03-project-management-ui

**Status:** ready-for-agent

- [ ] 创建 Character Service
- [ ] 实现获取人物列表 API（GET /api/v1/characters）
- [ ] 实现获取人物详情 API（GET /api/v1/characters/{id}）
- [ ] 实现更新人物 API（PUT /api/v1/characters/{id}）
- [ ] 实现获取人物音色档案 API（GET /api/v1/characters/{id}/voice-profiles）
- [ ] 实现人物头像上传
- [ ] 创建人物列表页面（CharacterList 组件）
