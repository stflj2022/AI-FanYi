# Ticket 022: M13 QA 模块

## 状态: done

## 优先级: 高

## 模块: M13 - Project QA & Human Review

## 描述

实现 M13 质检模块，对生成的中文配音视频进行技术质量和配音质量自动检查，生成 QA Report。

## 任务清单

- [ ] 创建 `src/filmdub/workers/qa/` 目录
- [ ] 实现 QAModule 类
- [ ] 实现技术质量检查（视频格式、音量、同步）
- [ ] 实现配音质量检查（音色一致性、情绪匹配）
- [ ] 实现 QA Report 生成（JSON/Markdown 格式）
- [ ] 实现问题分类和严重程度评级
- [ ] 编写单元测试
- [ ] 编写集成测试

## 技术要点

1. **技术质量检查**:
   - 视频格式验证（编码、分辨率、帧率）
   - 音频质量检查（音量、采样率、信噪比）
   - 音画同步检查（时间轴对齐）
   - 字幕检查（时间同步、文本正确）

2. **配音质量检查**:
   - 音色一致性（同人物音色是否稳定）
   - 情绪匹配（配音情绪与剧情是否匹配）
   - 语速合理性（语速是否与画面匹配）
   - 翻译质量（中文表达是否自然）

3. **QA Report**:
   - 总体评分
   - 问题列表（按严重程度分类）
   - 改进建议
   - 通过/不通过判定

## 输入

- 最终中文配音视频（来自 M12）
- 原始视频
- 人物数据库（来自 M04）
- 对白时间轴（来自 M08）

## 输出

- QA Report（JSON/Markdown 格式）

4. 单元测试通过率 > 90%
