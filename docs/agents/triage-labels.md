# Triage Labels

## Label Mapping

This maps the five canonical triage labels to the actual labels used in this repo's issue tracker.

| Canonical Role | GitHub Label |
|---------------|--------------|
| needs-triage | needs-triage |
| needs-info | needs-info |
| ready-for-agent | ready-for-agent |
| ready-for-human | ready-for-human |
| wontfix | wontfix |

## Usage

The `/triage` skill applies these labels to issues based on their state:
- `needs-triage` - New issues needing initial review
- `needs-info` - Issues requiring more information from reporter
- `ready-for-agent` - Issues ready for AI agent to work on
- `ready-for-human` - Issues requiring human intervention
- `wontfix` - Issues that won't be addressed
