# **02.3 数据库**

采用：
    
    
    SQLite

而不是直接用 JSON 当数据库。

原因：

- 单机部署简单
- 不需要 PostgreSQL
- 支持事务
- 支持关系查询
- 后期可以迁移 PostgreSQL
- 人物数据库需要关系结构

数据库：
    
    
    data/projects/<project_id>/project.db

* * *

# **02.4 数据表**

## **projects**
    
    
    CREATE TABLE projects (
        id TEXT PRIMARY KEY,
        canonical_title TEXT NOT NULL,
        original_title TEXT,
        year INTEGER,
        media_type TEXT,
        tmdb_id INTEGER,
        wikidata_id TEXT,
        confidence REAL,
        created_at TEXT,
        updated_at TEXT
    );

## **episodes**
    
    
    CREATE TABLE episodes (
        id TEXT PRIMARY KEY,
        project_id TEXT NOT NULL,
        season INTEGER NOT NULL,
        episode INTEGER NOT NULL,
        title TEXT,
        air_date TEXT,
        runtime INTEGER,
        tmdb_id INTEGER,
        confidence REAL,
        FOREIGN KEY(project_id) REFERENCES projects(id)
    );

## **actors**
    
    
    CREATE TABLE actors (
        id TEXT PRIMARY KEY,
        canonical_name TEXT NOT NULL,
        original_name TEXT,
        tmdb_id INTEGER,
        wikidata_id TEXT,
        gender TEXT,
        confidence REAL
    );

## **characters**
    
    
    CREATE TABLE characters (
        id TEXT PRIMARY KEY,
        canonical_name TEXT NOT NULL,
        actor_id TEXT,
        character_type TEXT,
        description TEXT,
        confidence REAL,
        FOREIGN KEY(actor_id) REFERENCES actors(id)
    );

## **character_aliases**
    
    
    CREATE TABLE character_aliases (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        character_id TEXT NOT NULL,
        alias TEXT NOT NULL,
        language TEXT,
        source_id TEXT,
        FOREIGN KEY(character_id) REFERENCES characters(id)
    );

## **appearances**
    
    
    CREATE TABLE appearances (
        character_id TEXT NOT NULL,
        episode_id TEXT NOT NULL,
        appearance_type TEXT,
        confidence REAL,
        PRIMARY KEY(character_id, episode_id)
    );

## **relationships**
    
    
    CREATE TABLE relationships (
        id TEXT PRIMARY KEY,
        subject_id TEXT NOT NULL,
        relation TEXT NOT NULL,
        object_id TEXT NOT NULL,
        valid_from_episode TEXT,
        valid_to_episode TEXT,
        confidence REAL
    );

# **02.5 Evidence 表**

这是整个系统的核心。
    
    
    CREATE TABLE evidence (
        id TEXT PRIMARY KEY,
    
        entity_type TEXT NOT NULL,
        entity_id TEXT NOT NULL,
    
        predicate TEXT NOT NULL,
        value TEXT NOT NULL,
    
        source_id TEXT NOT NULL,
    
        confidence REAL,
    
        retrieved_at TEXT NOT NULL
    );

例如：
    
    
    entity:
    character:walter_white
    
    predicate:
    portrayed_by
    
    value:
    actor:bryan_cranston

# **02.6 Sources 表**
    
    
    CREATE TABLE sources (
        id TEXT PRIMARY KEY,
    
        source_type TEXT NOT NULL,
    
        url TEXT NOT NULL,
    
        title TEXT,
    
        retrieved_at TEXT,
    
        content_hash TEXT,
    
        status TEXT,

例如：

# **02.16 Qwen Extraction**

Qwen 只接收清洗后的资料：
    
    
    ResearchDocument[]

Prompt 要求：
    
    
    仅根据提供的证据提取事实。
    
    禁止：
    1. 使用自身记忆补充事实
    2. 猜测
    3. 创造人物
    4. 创造人物关系
    
    每条事实必须引用 source_id。

输出严格 JSON：
    
    
    {
      "characters": [
        {
          "name": "Walter White",
          "actor": "Bryan Cranston",
          "aliases": [
            "Walter",
            "Mr. White"
          ],
          "evidence": [
            "src_001",
            "src_004"
          ]
        }
      ]
    }

* * *

# **02.17 Qwen Schema Validation**

Qwen 输出不能直接入库。

流程：
    
    
    Qwen
     ↓
    JSON Parse
     ↓
    Pydantic
     ↓
    Schema Validation
     ↓
    Evidence Validation
     ↓
    Database

例如发现：
    
    
    {
      "character": "Walter White",
      "actor": "Tom Hanks"
    }

如果没有证据：
    
    
    REJECT

而不是入库。

* * *

# **02.18 Entity Resolution**

不同网站：
    
    
    Walter White
    Walter H. White
    Mr. White
    Heisenberg

需要合并：
    
    
    character_id = char_walter_white

但：
    
    
    Walter White Jr.

不能合并。

规则：
    
    
    canonical entity
    +
    aliases
    +
    actor
    +
    external IDs

综合判断。

* * *

# **02.19 Character Resolution Score**

例如：
    
    
    Name similarity       0.90
    Actor match            1.00
    TMDB ID                1.00
    Wikidata ID             1.00
    Context                 0.95

最终：
    
    
    0.97

阈值：
    
    
    >= 0.90
    AUTO MERGE
    
    0.70--0.89
    REVIEW
    
    < 0.70
    KEEP SEPARATE

# **02.22 Relationship Ontology**

统一关系名称：
    
    
    spouse
    parent
    child
    sibling
    friend
    partner
    employer
    employee
    enemy
    relative
    colleague
    associate

不允许数据库里出现：
    
    
    wife_of
    married_to
    husband_of
    spouse_of

四种不同写法。

统一：
    
    
    spouse

* * *

# **02.23 Episode Appearance**

必须区分：
    
    
    series_cast
    episode_cast

例如：
    
    
    Walter
    episode 1 → yes
    
    Saul
    episode 1 → no

这样 MODULE 06 才能限制候选人物范围。

# **02.27 GPU 使用原则**

MODULE 02 **默认不长期占用 GPU**。

只有：
    
    
    Qwen extraction

才启动 LLM Worker：
    
    
    Web Research
     ↓
    释放网络/CPU资源
     ↓
    启动 Qwen
     ↓
    JSON extraction
     ↓
    释放 GPU
     ↓
    Verification

符合你要求的：

**处理完一个功能块，释放资源，再处理下一个。**
